# Exercicios iniciais
* Personalização de conta;
* Localização de serviços por categoria;
* Categorias dos serviços IAAS, PAAS, SAAS

No Microsoft Azure, as categorias de serviços em nuvem dividem-se em IaaS (Infraestrutura), PaaS (Plataforma) e SaaS (Software), variando conforme o nível de controle que o usuário tem sobre o ambiente:

1. IaaS (Infraestrutura como Serviço)

O Azure fornece o hardware virtual (servidores, redes e armazenamento), mas você gerencia o sistema operacional, middleware, dados e aplicações.
• Exemplos no Azure:
	• Máquinas Virtuais do Azure (Azure Virtual Machines): Servidores Windows ou Linux sob demanda.
	• Rede Virtual do Azure (Azure Virtual Network): Gerenciamento de redes e sub-redes isoladas.
	• Armazenamento do Azure (Azure Blob/Disk Storage): Discos e repositórios de arquivos em nuvem.

2. PaaS (Plataforma como Serviço)

O Azure cuida de toda a infraestrutura e do sistema operacional/middleware, deixando que você foque apenas no desenvolvimento e nos seus aplicativos.
• Exemplos no Azure:
	• Serviço de Aplicativo do Azure (Azure App Service): Hospedagem para sites e APIs sem gerenciar servidores.
	• Banco de Dados SQL do Azure (Azure SQL Database): Banco de dados relacional totalmente gerenciado.
	• Azure Functions: Computação sem servidor (serverless) para executar códigos por eventos.

3. SaaS (Software como Serviço)

O Azure (ou a Microsoft) entrega o software pronto para uso pela internet, onde você apenas consome a aplicação sem se preocupar com manutenção, atualizações ou infraestrutura.
• Exemplos associados à Microsoft/Azure:
	• Microsoft 365 (Word, Excel, Outlook na nuvem).
	• Dynamics 365 (Gestão de relacionamento com o cliente e ERP).
	• Azure DevOps (Ferramentas prontas para planejamento e entrega de software).

Resumo das Responsabilidades

• IaaS: Você gerencia OS, dados e aplicações; a Microsoft gerencia a física e virtualização.
• PaaS: Você gerencia apenas dados e aplicações; a Microsoft gerencia OS e infraestrutura.
• SaaS: Você apenas usa o aplicativo; a Microsoft gerencia tudo (exceto suas credenciais de acesso).
Se quiser, posso detalhar como migrar um serviço local (On-Premises) para uma dessas categorias no Azure ou aprofundar em casos de uso para o seu projeto.
